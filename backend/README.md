# FacultyLink API (Flask)

Shared REST backend for Admin web, Reviewer web, and Faculty Flutter.

- **Phase 1:** Auth (admin / reviewer / faculty), health check, private document upload + presigned view URLs.
- **Later:** OCR, full review workflow, evaluation settings API, email/OTP.
